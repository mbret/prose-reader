Welcome to the `prose` documentation. prose is a free and open-source **Reading System SDK** that renders any format in the browser. EPUB 3, comics (cbz, cbr, etc) and PDF are ready to use, and an [enhancer](/learn/enhancers) teaches it any other.

It does not mind where a book comes from either: the [streamer](/learn/streamer), or your own code, can serve it entirely in the browser, with no server at all, or from your own server or a React Native app.

<figure><img src="/images/prose-reader-demo.webp" alt="The prose demo reading Accessible EPUB 3 in a two-page spread, with the chapter, the pages and the progress below" width="563" height="378"></figure>

It is similar to what powers apps like Kindle, Kobo and other reading app alike. Unlike proprietary engines, this one is **free and made for the community**. It is designed to allow plugins and extend functionalities easily.

:::tip
In a nutshell, a reading system SDK will let you design your own reader the way you want while not having to deal with the complicated parts such as rendering, pagination, navigation, annotations, etc.
:::

This engine is web based. As long as you can render html, js and css you are good to go. Visit our [React Native](/react-native/introduction) section to see how it can be used in mobile apps.
