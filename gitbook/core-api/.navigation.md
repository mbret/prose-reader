# .navigation

## `.goTo(target, options?)`

```typescript
reader.navigation.goTo({ format: "cfi", value: cfi }, { animate: false })
reader.navigation.goTo({ format: "url", value: chapterUrl })
```

`target` is a `PositionTarget` (`{ format: string; value: string }`). Animation defaults to enabled. External formats are registered through `reader.positions`. Core loads and resolves the target, falling back to the named item's start when it cannot resolve the value. Unknown formats or invalid item indexes warn and fall back to the first item.

`goToCfi(cfi, options?)` and `goToUrl(url)` are convenience methods; URL convenience navigation disables animation.

## `.throttleLock()`

<pre class="language-typescript"><code class="lang-typescript"><strong>function throttleLock &#x3C;T>(params: {
</strong>    duration: number;
    trigger: Observable&#x3C;T>;
}) => Observable&#x3C;T>
</code></pre>

Create and hold a lock on the navigation that will release periodically only when the duration is reached. This is useful when letting users navigate with a scrubber for example. This will make sure the reader will not re-layout too often even if the user play with the scrubber too fast.

This does not prevent navigation, only the heavy recalculation that can occurs after (layout, pagination calculation, etc).

## API

#### `.outOfSpineBoundary$`

Emits when a navigation request targets a position outside the spine's current extent. Pure geometric primitive — no content-lifecycle semantics. For "end of book reached" with lazy-load awareness, compose with readiness signals (see `observeBookBoundaryReached`).

```typescript
reader.navigation.outOfSpineBoundary$
```
