# .navigation

## `.throttleLock()`

<pre class="language-typescript"><code class="lang-typescript"><strong>function throttleLock &#x3C;T>(params: {
</strong>    duration: number;
    trigger: Observable&#x3C;T>;
}) => Observable&#x3C;T>
</code></pre>

Create and hold a lock on the navigation that will release periodically only when the duration is reached. This is useful when letting users navigate with a scrubber for example. This will make sure the reader will not re-layout too often even if the user play with the scrubber too fast.

This does not prevent navigation, only the heavy recalculation that can occurs after (layout, pagination calculation, etc).

## API

#### `.outOfSpineBoundary$`

Emits when a navigation request targets a position outside the spine's current extent. Pure geometric primitive — no content-lifecycle semantics. For "end of book reached" with lazy-load awareness, compose with readiness signals (see `observeBookBoundaryReached`).

```typescript
reader.navigation.outOfSpineBoundary$
```

## `settled$`

`Observable<boolean>` reports whether navigation and visible-page pagination have settled. It starts false and waits for loaded visible items and generated page positions. Use `pagination.state$.pipe(filter(state => state.isSettled))` to persist the corresponding snapshot.

## `navigationState$`

The navigation state combines viewport activity with navigation readiness:

```typescript
type NavigationState = {
  activity: "busy" | "free"
  isSettled: boolean
}

reader.navigation.navigationState$.subscribe(({ activity, isSettled }) => {
  // "free" allows layout and pagination work to run.
  // isSettled also waits for ready content and matching pagination.
})
```

A new request invalidates settlement immediately, including repeated requests for the same position. Settlement is derived from navigation activity and content readiness; there is no independently maintained settlement flag. The stream completes when the reader is destroyed.

`NavigationState` is exported by core. `navigation.settled$` is the distinct projection of this state's `isSettled` field. Both wait for ready content and matching pagination, including the pagination enhancer's delayed snapshot. Persist progress from `pagination.state$` using its `isSettled` field.
